## 🎸 Про проект

Сучасний адаптивний веб-сайт для майстерні музичних аксесуарів D B Studio, що спеціалізується на 3D-друку.

## ✨ Особливості

- 📱 **Повністю адаптивний** (мобільні, планшети, десктоп)
- ⚡ **Висока продуктивність** 
- 🎨 **Сучасний дизайн** з анімаціями
- ♿ **Доступність** (accessibility)
- 🔧 **Проста установка**

## 🛠 Технології

- HTML5, CSS3, JavaScript
- GSAP для анімацій
- ScrollTrigger для скрол-ефектів
- Font Awesome для іконок

## 🚀 Швидкий старт

1. Клонуй репозиторій
2. Відкрий `index.html` у браузері
3. Або зайди на GitHub Pages
